# 20101-gun

一個簡單的網站，包含一個會瞄準鼠標的火炮。

## 功能
- 火炮位於左下角，會自動瞄準滑鼠位置。
- 點擊滑鼠左鍵發射子彈到滑鼠位置。

## 技能介紹
- `E`：發動特殊技能，快速連續發射 15 顆子彈，每顆子彈有隨機角度偏移。
- `R`：發射一顆綠色大彈，擊中後會爆炸成大量小彈。
- `F`：發射 10 顆橙色強化子彈，擊中敵人後會持續前進。
- `Q`：發射 5 顆紫色追蹤彈，會自動追蹤附近敵人。

## 如何運行
1. 啟動本地服務器：`python3 -m http.server 8080`
2. 在瀏覽器中打開 `http://localhost:8080`
